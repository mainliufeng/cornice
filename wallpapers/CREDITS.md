# Wallpapers shipped with cornice

`default.png` is generated for cornice (a plain gradient, no photograph) and is
covered by the project's MIT licence, like the rest of the repository.

Cornice does not ship photographs. The wallpaper directory it scans by default is
`~/Pictures/wallpapers` (see `background.dir` in the configuration); put whatever
you have the rights to use in there. `cornice background next|prev|set <path>`
cycles it, and the background layer steps aside for mpvpaper/hyprpaper/swaybg/
swww/wbg unless `background.force` is set.
